# RNA refinement 第二次训练评估分析

## 1. 评估设置

- checkpoint：`epoch=12-step=39442.ckpt`
- 模型：one-step residual refinement + mobility gate
- 主指标：在 observed atoms 上进行 Kabsch 对齐后的 RMSD
- improvement 定义：`input RMSD - refined RMSD`，正值表示 refinement 后更接近 native
- 验证集：111 条 PDB RNA 链，实际评估 21,322 个 Protenix 候选
- 测试集：82 条 PDB RNA 链，实际评估 15,310 个 Protenix 候选
- 同一 PDB 的候选先汇总为一条 PDB-chain 结果；约 200 个候选不能视为 200 个独立 RNA 样本

## 2. 原始总体结果

| 数据集 | candidate 平均 RMSD | candidate 胜率 | PDB-chain 平均提升 | PDB-chain 中位提升 | PDB-chain 胜率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| validation | 7.9468 → 7.6501 Å | 79.26% | +0.2853 Å | +0.0340 Å | 81.98% |
| test | 9.2402 → 7.6228 Å | 80.95% | +1.5105 Å | +0.0550 Å | 84.15% |

直接看原始结果，模型在多数候选和多数 PDB 链上都使 RMSD 下降。但是平均值远大于中位数，说明总体平均提升被少数极端受益链明显拉高，不能只汇报 mean。

## 3. 典型链上的真实效果

### 验证集

- 111 条链的平均提升为 +0.2853 Å，但中位数仅 +0.0340 Å。
- 提升超过 0.1 Å：42/111；超过 0.5 Å：17/111。
- 变差超过 0.1 Å：11/111；变差超过 0.5 Å：3/111。
- 提升最大的 5 条链贡献了全部 PDB-chain improvement 总和的约 67.5%。
- 去掉提升最大的 5 条后，平均提升降为约 +0.0970 Å。

### 测试集

- 82 条链的平均提升为 +1.5105 Å，但中位数仅 +0.0550 Å。
- 提升超过 0.1 Å：34/82；超过 0.5 Å：22/82。
- 变差超过 0.1 Å：6/82；变差超过 0.5 Å：1/82。
- 提升最大的 5 条链贡献了全部 PDB-chain improvement 总和的约 53.2%。

因此，这个模型的结论应表述为：多数链方向上是改善的，但对“典型 RNA 链”的改善幅度较小；少数短链出现了非常大的提升。

## 4. 链长分析

### 原始分层结果

| 数据集 | 长度 | PDB 数 | 平均提升 |
| --- | --- | ---: | ---: |
| validation | ≤50 nt | 54 | +0.4783 Å |
| validation | 51–100 nt | 21 | +0.1927 Å |
| validation | 101–200 nt | 14 | +0.1264 Å |
| validation | >200 nt | 22 | +0.0013 Å |
| test | ≤50 nt | 40 | +3.0812 Å |
| test | 51–100 nt | 17 | +0.0164 Å |
| test | 101–200 nt | 7 | +0.0344 Å |
| test | >200 nt | 18 | +0.0052 Å |

- improvement 与长度的 Spearman 相关：validation 为 -0.3508，test 为 -0.7433。
- 去掉 test 中全部 16 nt 链后，相关仍为 -0.5822，说明“链越长、改善越弱”不完全是极端短链造成的。
- test 中长度 ≥51 nt 的 42 条链，平均提升仅 +0.0146 Å，中位数 +0.0027 Å，bootstrap 95% CI 为约 [-0.0013, 0.0299] Å，基本无法证明有稳定且有实际意义的改善。
- test 中去掉 16 nt 链后，剩余 27 条 ≤50 nt 短链平均提升 +0.3593 Å，中位数 +0.2652 Å，仍显示模型对短链有真实正向作用。

注意：长链虽然 PDB-chain win rate 仍可能较高，但其 improvement 往往只有千分之几 Å。这种“胜率高、幅度接近零”的情况，不能解释成有效 refinement，更像模型几乎没有移动构象。

## 5. 输入质量分析

测试集中，输入 RMSD ≤2 Å 的 4 条链平均反而变差 0.3138 Å，只有 25% 的链改善。最明显的例子：

| PDB | 长度 | input RMSD | refined RMSD | improvement | candidate 胜率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 9OD4 A | 23 | 1.4889 | 2.3551 | -0.8662 Å | 1.5% |
| 23JZ A | 35 | 1.3054 | 1.5924 | -0.2870 Å | 0% |
| 8Q6N A | 46 | 2.1247 | 2.2484 | -0.1237 Å | 0% |
| 8VT5 A | 60 | 1.8027 | 1.9047 | -0.1020 Å | 0% |

这说明当前 mobility/no-regret 机制还不能可靠保护已经接近 native 的输入。后续应重点优化“何时不动”，而不仅是提高对差构象的修正幅度。

## 7. 必须汇报的数据泄漏/同源性问题

根据本地 `final_manifest.tsv` 和 `rna_chain_sequences.csv` 对 canonical sequence 做完全一致匹配：

- validation 中至少 21/111 条链与训练集存在完全相同序列。这些链平均提升 +0.9854 Å；其余 90 条链平均提升 +0.1220 Å，中位数 +0.0334 Å，bootstrap 95% CI 约 [0.0468, 0.1979] Å。
- validation 提升最大的 7EFG、7EFH，与训练集 4C40、4CS1、6Q8V 的序列完全相同。
- test 中至少 6/82 条链与训练集 3ND4 A 的序列完全相同：36LL、9CSO、9CSP、9MDW、9MDX、9MDY。这 6 条链平均提升 +13.0577 Å。
- test 前 13 名全部为 16 nt；其中 6 条与训练序列完全相同，其余 7 条与该训练序列的逐位 identity 为 87.5%–93.75%。因此即使不是完全重复，也属于极近同源短链。
- 去掉全部 13 条 16 nt 链后，test 剩余 69 条链的平均提升从 +1.5105 Å 降为 +0.1495 Å，中位数 +0.0265 Å，bootstrap 95% CI 约 [0.0716, 0.2330] Å，PDB-chain 胜率仍为 81.16%。
- validation 内部还有 13 个完全重复序列组、共 46 条链；test 内部有 3 个重复序列组、共 10 条链。因此把每个 PDB 都当成独立样本仍会低估不确定性。

所以，`test 平均提升 1.5105 Å` 不能作为独立泛化性能直接汇报。更稳妥的结论是：排除最明显的 16 nt 同源簇以后，模型仍有小幅正向效果，但提升主要集中在短链；中长链效果接近零。

## 8. 评估覆盖率问题

- validation 理论候选数为 111×200=22,200，实际为 21,322，缺少 878 个。
- test 理论候选数为 82×200=16,400，实际为 15,310，缺少 1,090 个。
- 缺失主要集中在长链。validation 的 7PTQ 只有 1 个候选，7PTS 只有 3 个，7PTK 和 7QDU 各 8 个；test 的 9M79 只有 1 个，9LEL 只有 2 个，9ISV 只有 20 个。
- 因此个别长链的 per-PDB 均值很不稳定，长链结论还需要在候选生成完整后复核。

## 9. 建议的下一步

1. 重新审计并修复训练/验证/测试的序列去重与同源过滤；至少以 sequence cluster 为单位切分，不能只按 PDB ID 去重。
2. 修复后重新选择 validation checkpoint，再对锁定的 test 只评估一次。当前 test 不应用于继续挑 checkpoint 或调超参数。
3. 每个 PDB 的约 200 个候选都保留评估，用来衡量候选间稳定性；最终统计以 PDB-chain 或 sequence-family 为单位汇总，不能把所有候选当独立样本计算显著性。
4. 同时汇报 mean、median、提升超过 0.1/0.5 Å 的比例、恶化超过 0.1/0.5 Å 的比例，避免被少数极端样本误导。
5. 下一版模型优先解决两点：中长链几乎不移动；低输入 RMSD 的优质构象会被破坏。可考虑更强的 identity/no-op 训练、按置信度或预测风险控制 mobility，以及显式优化 worsened fraction。

## 10. 可直接口头汇报的版本

第二次训练选用的是 epoch 12、step 39442 的 checkpoint。原始结果上，验证集 111 条链的 PDB-level 平均 RMSD 改善是 0.285 Å，测试集 82 条链是 1.511 Å，PDB 胜率分别约 82% 和 84%。但是这两个平均值都有明显长尾，验证集和测试集的中位改善只有 0.034 Å 和 0.055 Å，说明典型样本的提升其实较小。

分长度看，模型主要对短链有效。测试集中去掉 16 nt 的特殊同源簇后，剩余短链平均还能改善约 0.36 Å；但长度 51 nt 以上的 42 条链平均只改善 0.015 Å，中位数 0.003 Å，基本相当于没有明显 refinement。另一个问题是输入已经很好时容易被破坏，测试集中 input RMSD 小于等于 2 Å 的 4 条链平均反而变差 0.314 Å。

我还发现数据切分存在需要优先处理的同源泄漏。测试集提升最大的 13 条全部是 16 nt 链，其中 6 条与训练集 3ND4 的序列完全相同，其余 7 条序列 identity 也有 87.5% 到 93.75%。去掉这 13 条以后，测试集平均改善从 1.511 Å 降到 0.149 Å，中位改善是 0.027 Å；所以 1.511 Å 不能当作独立测试泛化性能。比较可信的结论是：模型已经学到对部分短链和较差初始构象的小幅修正能力，但当前对中长链基本无效，而且对接近 native 的输入保护不足。下一步应先修复 sequence-family 级别的数据切分，再重新做 validation 选模和一次性 test 评估，同时加强 no-op/protection 机制。
